# A1200KBv2-BAEK</br>

What's a BAEK? It's a Big-Ass Enter Key.</br>

This is the BAEK version of the A1200KBv2 project. It is the same but for the BAEK itself and longer Left Shift key, just like the North American A2000 keyboard. These keys remove the need for two keys that are found in most A1200 keyboards, those that are blank in UK/US languages and are sometimes used for special characters in other languages.</br>
The Left Shift key is a conventionally stabilised key, same as the Right Shift. The BAEK uses the same kind of stabiliser at its base but adds another single stabiliser at the top. The key available does not provide for a vertical wire as keyboard with BAEK sometimes use - when pressing at the very top it will be slightly stiffer, but it seems to work fine.</br>
All other parts of this keyboard are substantially the same as the A1200KBv2 project.</br>
